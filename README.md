# AuraFinance

**A premium, dark-first Android financial manager UI built with Jetpack Compose and Material 3**

`Kotlin` · `Jetpack Compose` · `Material 3` · `UI-only showcase`

By **Sharat S Unnithan**

</div>

## Overview

AuraFinance is a UI showcase of an ultra-advanced personal finance app. It covers **7 modules and 50 screens**, designed with an obsidian background, white typography and an emerald accent, using micro-rounded cards, gradient borders and edge-to-edge layouts.

This repository is **UI only**. There is no backend, database or network layer, and all numbers are sample data.

## What's in the repo

- `AuraFinanceUI.kt`: a single-file Jetpack Compose UI with the theme, Canvas charts (pie, line, candlestick), a 50-screen registry and navigation scaffold.
- `screenshots/`: 50 PNG images, one per screen, at 2x resolution.
- `aurafinance-showcase.html`: a Figma-style gallery of all 50 screens as phone mockups. Open it in any browser.

### Implementation status

- Fully built in Compose: Net Worth dashboard, Equities with candlestick chart, and the navigation shell.
- Other screens are registered in navigation and shown in the HTML showcase. Compose versions are in progress.

## Getting started

1. Install [Android Studio](https://developer.android.com/studio).
2. Create or open the project with package `com.aura.finance` and minSdk 26.
3. Add `AuraFinanceUI.kt` to `app/src/main/java/com/aura/finance/`.
4. Add dependencies:
   ```kotlin
   implementation("androidx.compose.material:material-icons-extended:1.7.6")
   implementation("androidx.navigation:navigation-compose:2.8.5")
   ```
5. In `MainActivity`, call `AuraApp()` inside `setContent { }`, then press Run.

To preview without running, open `AuraFinanceUI.kt` and use the Split view to see `AuraPreview`.
